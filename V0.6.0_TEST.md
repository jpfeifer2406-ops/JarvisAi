# COMPUTER v0.6.0 TEST

Status: **IMPLEMENTED ON FEATURE BRANCH — TARGET-PC VALIDATION PENDING**

Branch: `feature-v0.6.0`

v0.6.0 turns the voice-first cockpit into a broader local COMPUTER shell while
keeping the current test machine CPU-first and keeping all active development in
one Git working folder.

## Implemented

### CPU-first test profile

- faster-whisper default changed to `base / cpu / int8 / beam_size=1`.
- Victoria TTS is explicitly CPU.
- Ollama keeps the existing qwen2.5:1.5b model with a smaller local context/output
  budget for test latency.
- CUDA is no longer the default path for STT.

### Victoria German TTS repair

The v0.5.2 run loaded the Victoria checkpoint but produced only technical noise.
v0.6.0 follows the published kikiri reference inference path:

- pinned German-capable Kokoro fork,
- pinned Misaki German DEG2P frontend,
- `lang_code="d"`,
- Victoria's training-compatible Kokoro config,
- 24 kHz playback,
- CPU inference.

This is compile/CI-tested only until the Captain confirms intelligible speech on
the target Windows PC.

### Wake word: COMPUTER

- User-facing wake word is now `Computer`.
- Uses the community `computer_v2.onnx` openWakeWord model on CPU.
- The small model downloads automatically on first start.
- The old Hey Jarvis model is no longer the configured runtime wake word.

The community model is suitable for development testing, but its training-data
provenance still requires a commercial-release review.

### Settings drawer

The old always-visible live/system console is replaced by a hidden settings
drawer opened with the gear icon or the voice command:

- `Einstellungen öffnen`
- `Einstellungen schließen`

Tabs:

- Verbindungen
- System
- Diagnose
- Tools

### Integrations shell

Settings now exposes explicit status cards for:

- **Phone / KDE Connect** — detects whether the free KDE Connect desktop tool is
  present and provides the official setup link.
- **Browser / COMPUTER Browser Bridge** — a bundled local Chromium extension
  reports the active tab title/URL to COMPUTER. v0.6.0 keeps it read-only.
- **Google Drive / OAuth** — integration slot and credential state are visible.
  Actual Drive access remains disabled until the user supplies their own OAuth
  desktop credentials and explicitly authorizes access.

No integration is reported as connected unless COMPUTER can verify it.

### Call overlay

Voice commands:

- `Anrufmodus öffnen`
- `Anrufmodus schließen`

The dedicated Call overlay is implemented. It intentionally does not pretend
telephone control exists before an authorized phone bridge is connected.

### Creative-Werkstatt

Voice commands:

- `Werkstatt öffnen`
- `Werkstatt schließen`

The workshop can create real files inside the local `workspace/` folder:

- DOCX
- PDF
- TXT

LLM tools were added for create/read/revise/list. Existing originals are not
silently overwritten. DOCX/TXT revisions create a new copy. PDF revisions are
rebuilt from extracted text, so layout preservation is not claimed.

### Single-folder update model

Use one Git clone for COMPUTER. Versions are branches/commits, not separate
folders.

- `install.bat` remains for the first installation.
- `update.bat` performs a fast-forward Git update and synchronizes dependencies
  inside the existing `.venv` without deleting the environment.
- Generated workshop files live under `workspace/` and are ignored by Git.

## Target-PC validation order

1. Stop the old COMPUTER process.
2. Switch the existing clone to `feature-v0.6.0`.
3. Run `update.bat` once because Kokoro/Misaki/document dependencies changed.
4. Start `start.bat`.
5. Confirm startup says wake word COMPUTER and CPU test profile.
6. Say `Computer` several times and measure wake reliability.
7. Confirm Victoria says an intelligible German startup phrase with no digital noise.
8. Speak one short German command and record STT latency.
9. Open/close Settings by gear and voice.
10. Open/close Call overlay by voice.
11. Open Creative-Werkstatt and create one DOCX and one PDF.
12. Open News Europe and confirm the already-fixed regional focus still works.
13. Load the local browser extension and confirm Browser status becomes connected.
