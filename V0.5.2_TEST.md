# COMPUTER v0.5.2 TEST — Voice-first cockpit

Status: IMPLEMENTED IN FEATURE BRANCH / TARGET-PC VALIDATION PENDING

Branch: `feature-v0.5.2-voice-first`

## Scope

v0.5.2 turns the browser cockpit into a voice-first interface while retaining
the v0.5.1/news-globe functionality.

### German Victoria TTS

- Default engine: `kikiri-tts/kikiri-german-victoria`
- Language: German
- Model: `kikiri_german_victoria_ep10.pth`
- Voicepack: `voices/victoria.pt`
- Runtime: CPU in this test build
- First voice use downloads roughly 330 MB of model weights.
- If TTS cannot load, COMPUTER keeps running without voice instead of crashing.

The currently installed Kokoro package may not yet register German. COMPUTER
therefore adds the minimal `de -> d` language mapping in memory at runtime and
uses the existing espeak German G2P path. No installed package file is modified.

### Voice-first cockpit

The text conversation is hidden by default. The central COMPUTER core remains
visible and reacts to runtime state:

- standby/online: cyan
- listening: green
- processing: amber
- speaking: blue

In the closed state the core is enlarged, floats subtly, and has independent
orbit rings.

Open the text input with:

- voice: `Eingabe öffnen`
- voice alternatives: `Chat öffnen`, `Texteingabe öffnen`
- keyboard: F2

Close it with:

- voice: `Eingabe schließen`
- voice alternatives: `Chat schließen`, `Texteingabe schließen`
- browser keyboard: Escape when the news view is not open

The UI commands are deterministic and do not require an LLM call.

## Validation required on the target PC

1. First-start Victoria download completes.
2. Startup phrase is intelligible German: `COMPUTER online. Bereit, Captain.`
3. Wake word still activates the session.
4. `Eingabe öffnen` opens and focuses the browser text field.
5. `Eingabe schließen` returns to the floating voice core.
6. F2 opens the input view.
7. News Globe still opens and focuses regions.
8. `Ruhemodus` still returns to standby.
9. TTS failure still leaves the cockpit usable.

## Known limitations

- Temporary wake word remains `Hey Jarvis`.
- Victoria is experimental until validated on the Windows target.
- Victoria currently runs on CPU; performance tuning is deferred until better
  compute/server hardware is available.
- The News Globe still loads some visual assets from CDNs.
- READ/PREPARE/EXECUTE/CRITICAL is not yet enforced by a complete code-level
  permission broker.
